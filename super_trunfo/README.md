# Super Trunfo

O jogo super trunfo é um jogo para aprender geografia se divertindo. Cartas são cadastradas com informações sobre países, posteriormente os jogadores embaralham e dividem as cartas entre os jogadores, e em turnos comparam alguma informação específica sobre os países, e aquele que tiver o país com a melhor pontuação naquela característica ganha a carta dos outros jogadores. O jogador que finalizar com mais cartas ganha.
